# Prólogo — O Último Dia

Nero sai de casa para buscar Lina. O jogador atravessa quatro regiões:

1. **Bairro operário** — casas, vapor, crianças, vizinhos.
2. **Mercado industrial** — bancas, taxas, guarda intimidando comerciante.
3. **Avenida central** — elite, propaganda, coche a vapor.
4. **Caminho da escola** — jardim, pais, falsa calma.

A cutscene dispara no marcador invisível perto da escola: Lina corre, um veículo avança, a tela vai a preto, o som do impacto toca, silêncio, título.

Não há combate obrigatório. Conversas com E.
