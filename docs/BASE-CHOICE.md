# Auditoria do repositório anterior

O projeto aberto era um piloto Phaser 4 + Vite. Foram preservados movimento, física Arcade, cenas, Docker e testes. A identidade cyberpunk (NEON FALL, Vesper-9, NEXUS, Neon Dash como nome) foi removida da interface e da narrativa.

A habilidade de dash permanece no código como mobilidade futura, desligada no prólogo.
