# Fontes de arte

`art/source` guarda as pinturas usadas pelo pipeline.

`art/previews` guarda contact sheets e screenshots de validação.

As fontes são originais deste projeto, geradas para Black Bird: Revolução. Não são assets de Blasphemous, Dishonored ou qualquer jogo comercial.

Para regenerar os PNGs de jogo:

```bash
npm run art
```

Arquivos editáveis futuros (Aseprite/LibreSprite) devem entrar em `art/aseprite/` quando existirem. Hoje o trabalho de pixel final ainda precisa de um artista dedicado.
