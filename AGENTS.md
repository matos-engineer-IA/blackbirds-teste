# Black Bird: Revolução — continuidade

Antes de alterar o jogo, leia `docs/PROGRESSO_CODEX.md` e a seção 00 de
`docs/BLACK_BIRD_DOCUMENTO_MESTRE_CODEX.md`. Siga a ordem de leitura por disciplina.

Evolua este projeto Phaser/TypeScript. Preserve o cânone e a abertura; Winsth
permanece na arena técnica. Arte REVIEW/BLOCKOUT não possui aprovação artística.

`npm test` e `npm run build` são as verificações básicas. Mudanças em movimento,
colisão, câmera, diálogo ou combate exigem execução no navegador e inspeção das
capturas. Veja os scripts `test:browser`, `test:combat:browser` e os comandos no
arquivo de progresso. Fixtures de teste não comprovam travessia normal.

Atualize o progresso com resultados reais, limitações e próxima ação concreta.
Não reclassifique testes planejados como executados nem pendências artísticas
como concluídas. Mantenha especificação, status e evidências separados.
